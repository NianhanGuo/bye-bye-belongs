# bye bye belongs

## Shared
- Audience: people who have lost belongings.
- Inspiration: Kafka's lost doll story.
- Visitors describe a lost belonging and optionally select a photograph.
- The belonging writes a letter back.
- Quiet, playful style; muddy green-gray, bright red, dark brown.
- Prototype uses locally composed letters; no external AI service.
- Photographs stay on the device and are not analyzed.

## Homepage
- Site name, brief introduction, object form, sample letter.
- Name and description required; photo optional.
- Rounded lettering and restrained red accents.
- A letter from a little red scarf is visible on the homepage.

## Letter page
- Display an imagined letter using the submitted name and description.
- Gentle adventures, comfort, and remembrance.
- Return link to write about another belonging.

## Constraints
- No ads, public uploads, social feed, or horizontal scrolling on phones.
- Plain HTML, CSS, and JavaScript.
